### **Project Blueprint: `CodeScribe`**

**1. Project Definition (The Elevator Pitch)**

  * **Project Name:** `CodeScribe`
  * **One-Liner:** An AI-powered GitHub Action that automatically generates and updates a complete documentation website for your Python project on every `git push`.
  * **The Problem:** Writing and maintaining documentation is tedious. As code evolves, documentation becomes stale, inaccurate, and useless.
  * **The Solution:** `CodeScribe` monitors a repository. On each push, it:
    1.  Parses the codebase to understand its structure.
    2.  Uses an LLM to generate/update docstrings for any undocumented code.
    3.  Analyzes the `git` commit history for that file to write a "Recent Changes" summary.
    4.  Builds and deploys a beautiful, searchable documentation website (using MkDocs).

**2. Core Tech Stack**

  * **Language:** **Python 3.10+**
  * **Core Logic:**
      * **Code Parsing:** Python's built-in `ast` (Abstract Syntax Tree) module.
      * **Git Analysis:** `GitPython` library (to interact with the repo).
  * **AI Integration:** `openai` library (to call an LLM like GPT-4o-mini or GPT-4).
  * **Doc Generation:** `MkDocs` (static site generator) + `Jinja2` (for templating Markdown).
  * **Automation:** **GitHub Actions** (to run the script on `git push`).

### Phase 1: The Core Parser (`parser.py`)

  * **Goal:** Read a single Python file and extract its class/function structure.

  * **`codescribe/parser.py`:**

    ```python
    import ast

    def get_source_segment(source_lines, node):
        """Helper to get the full source code of a node."""
        # ast.get_source_segment is available in Python 3.8+
        # This is a simplified version for nodes with line numbers
        lines = source_lines[node.lineno - 1:node.end_lineno]
        return "".join(lines)

    def parse_python_file(file_path):
        """Parses a Python file and extracts its structure."""
        with open(file_path, 'r') as f:
            source_code = f.read()
        
        source_lines = source_code.splitlines(keepends=True)
        tree = ast.parse(source_code)
        
        structure = {'classes': [], 'functions': []}
        
        for node in ast.walk(tree):
            if isinstance(node, ast.FunctionDef):
                function_data = {
                    'name': node.name,
                    'args': [arg.arg for arg in node.args.args],
                    'docstring': ast.get_docstring(node),
                    'code': get_source_segment(source_lines, node)
                }
                # Check if it's a method in a class
                parent = getattr(node, 'parent', None)
                if isinstance(parent, ast.ClassDef):
                    # Find the class it belongs to and add it
                    for c in structure['classes']:
                        if c['name'] == parent.name:
                            c['methods'].append(function_data)
                            break
                else:
                    structure['functions'].append(function_data)
                    
            elif isinstance(node, ast.ClassDef):
                # Set parent for child nodes
                for child in node.body:
                    if isinstance(child, ast.FunctionDef):
                        child.parent = node
                        
                structure['classes'].append({
                    'name': node.name,
                    'docstring': ast.get_docstring(node),
                    'code': get_source_segment(source_lines, node),
                    'methods': []
                })
        
        return structure

    ```

    ```python
    from jinja2 import Environment, FileSystemLoader
    import os

    def generate_markdown(structure, template_dir, template_name, module_name, summary=None):
        """Generates Markdown from a structure using a Jinja2 template."""
        env = Environment(loader=FileSystemLoader(template_dir))
        template = env.get_template(template_name)
        
        output = template.render(
            module_name=module_name,
            structure=structure,
            summary=summary
        )
        return output
    ```

### Phase 3: The AI Enhancement Layer (`ai_enhancer.py`)

  * **Goal:** Use an LLM to fill in any missing docstrings.

  * **`codescribe/ai_enhancer.py`:**

    ```python
    import openai
    import os
    from dotenv import load_dotenv

    load_dotenv()
    client = openai.OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

    def get_ai_docstring(function_code):
        """Generates a docstring for a function using an LLM."""
        prompt = f"""
        You are an expert Python developer writing Google-style docstrings.
        Generate a professional docstring for the following Python function.
        Only return the docstring itself, enclosed in triple quotes.
        Do not include any other text, explanation, or the function code itself.

        Function:
        {function_code}
        """
        
        try:
            response = client.chat.completions.create(
                model="gpt-4o-mini", # Cheaper and faster
                messages=[{"role": "user", "content": prompt}]
            )
            docstring = response.choices[0].message.content.strip()
            # Clean up the response to be just the docstring
            if docstring.startswith('"""') and docstring.endswith('"""'):
                return docstring.strip('"""').strip()
            return docstring

        except Exception as e:
            print(f"Error generating docstring: {e}")
            return "AI generation failed."

    def enhance_structure_with_ai(structure):
        """Iterates over the structure and fills in missing docstrings."""
        
        for func in structure['functions']:
            if not func['docstring']:
                print(f"Generating docstring for function: {func['name']}...")
                func['docstring'] = get_ai_docstring(func['code'])
                
        for class_obj in structure['classes']:
            if not class_obj['docstring']:
                print(f"Generating docstring for class: {class_obj['name']}...")
                # You'd need a slightly different prompt for classes
                class_obj['docstring'] = get_ai_docstring(class_obj['code'])
                
            for method in class_obj['methods']:
                if not method['docstring']:
                    print(f"Generating docstring for method: {method['name']}...")
                    method['docstring'] = get_ai_docstring(method['code'])
                    
        return structure
    ```

### Phase 4: The "Wow" Factor - Git Analysis (`git_analyzer.py`)

  * **Goal:** Get the last few commit messages for a file and use AI to summarize them.

  * **`codescribe/git_analyzer.py`:**

    ```python
    import git
    from .ai_enhancer import client # Re-use the AI client

    def get_commit_history(repo_path, file_path, limit=5):
        """Gets the last 'limit' commit messages for a specific file."""
        try:
            repo = git.Repo(repo_path)
            commits = list(repo.iter_commits(paths=file_path, max_count=limit))
            return [c.message.strip() for c in commits]
        except Exception as e:
            print(f"Error getting git history: {e}")
            return []

    def summarize_commits_with_ai(commit_messages):
        """Uses an LLM to summarize a list of commit messages."""
        if not commit_messages:
            return "No recent changes found for this file."
            
        prompt = f"""
        You are a technical project manager. Summarize the following list of
        git commit messages into a single, 2-3 sentence "Recent Changes" summary
        in plain English for a documentation website.

        Commits:
        - {"\n- ".join(commit_messages)}
        """
        
        try:
            response = client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{"role": "user", "content": prompt}]
            )
            return response.choices[0].message.content.strip()
        except Exception as e:
            print(f"Error summarizing commits: {e}")
            return "Could not summarize recent changes."
    ```

### Phase 5: Tying it all together (The Main Scripts)

  * **`run_local.py`:** (For you to test locally)

    ```python
    import os
    from codescribe.parser import parse_python_file
    from codescribe.generator import generate_markdown
    from codescribe.ai_enhancer import enhance_structure_with_ai
    from codescribe.git_analyzer import get_commit_history, summarize_commits_with_ai

    # --- Config ---
    TEST_FILE_PATH = 'codescribe/parser.py' # Test on its own code
    REPO_PATH = '.'
    TEMPLATE_DIR = 'templates'
    TEMPLATE_NAME = 'module.md.j2'
    OUTPUT_DIR = 'docs'
    # ---

    def main():
        print(f"Starting CodeScribe for: {TEST_FILE_PATH}")
        
        # 1. Parse the file
        print("Parsing file structure...")
        structure = parse_python_file(TEST_FILE_PATH)
        
        # 2. Enhance with AI docstrings
        print("Enhancing structure with AI...")
        enhanced_structure = enhance_structure_with_ai(structure)
        
        # 3. Get Git history
        print("Analyzing Git history...")
        commits = get_commit_history(REPO_PATH, TEST_FILE_PATH)
        summary = summarize_commits_with_ai(commits)
        
        # 4. Generate Markdown
        print("Generating Markdown...")
        module_name = os.path.basename(TEST_FILE_PATH)
        md_content = generate_markdown(
            enhanced_structure,
            TEMPLATE_DIR,
            TEMPLATE_NAME,
            module_name,
            summary
        )
        
        # 5. Write to docs folder
        output_path = os.path.join(OUTPUT_DIR, f"{module_name.replace('.py', '.md')}")
        with open(output_path, 'w') as f:
            f.write(md_content)
            
        print(f"Successfully generated docs: {output_path}")
        print("\nRun 'mkdocs serve' to see the results.")

    if __name__ == "__main__":
        main()
    ```

### Phase 6: The Automation (GitHub Actions)

  * **Goal:** Run this process automatically on every push to the `main` branch.

  * **`.github/workflows/docs.yml`:**

    ```yaml
    name: CodeScribe - Generate & Deploy Docs

    on:
      push:
        branches:
          - main

    permissions:
      contents: write # Needed to push to gh-pages

    jobs:
      build-and-deploy:
        runs-on: ubuntu-latest
        steps:
          - name: Checkout code
            uses: actions/checkout@v4
            with:
              fetch-depth: 0 # Needed for GitPython to see all history

          - name: Set up Python
            uses: actions/setup-python@v5
            with:
              python-version: '3.10'

          - name: Install dependencies
            run: |
              pip install -r requirements.txt
              pip install mkdocs-material # Use a nice theme

          - name: Run CodeScribe
            # This is a simplified loop. A real script would be more robust.
            run: |
              mkdir -p docs # Ensure docs dir exists
              for file in $(find codescribe -name "*.py"); do
                # This is a simplified version of run_local.py
                # You should create a main.py that handles all files
                python -m your_main_script --file $file --output-dir docs
              done
            env:
              OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}

          - name: Deploy to GitHub Pages
            uses: peaceiris/actions-gh-pages@v3
            with:
              github_token: ${{ secrets.GITHUB_TOKEN }}
              publish_dir: ./site # MkDocs builds to the 'site' directory
    ```

  * **Final Step:** You must create a `your_main_script.py` that is designed to be run by the GitHub Action. It would loop through all `.py` files in the repository (found using `glob` or `os.walk`) and run the Phase 1-4 logic for each one, saving the `.md` file in the `docs/` directory.
